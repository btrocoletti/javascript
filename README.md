 Proyecto Final JavaScript

Tienda online para mascotas

Este proyecto es una pequeña tienda online desarrollada como entrega final del curso de JavaScript.

La aplicación permite visualizar productos, agregarlos a un carrito y finalizar una compra simulada.

Funcionalidades

- Visualización de productos desde un archivo JSON
- Filtro de productos por categoría
- Carrito de compras dinámico
- Agregar y quitar productos del carrito
- Cálculo automático del total
- Confirmación de compra
- Persistencia de datos con localStorage

Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Fetch API
- LocalStorage

 Librerías utilizadas

- SweetAlert2
- Toastify
